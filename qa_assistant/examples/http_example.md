# /http example

## Вход

`/http 405`

## Идеальный ответ

## Что означает
405 Method Not Allowed означает, что endpoint существует, но HTTP-метод не разрешён.

## Когда возникает
Например, endpoint поддерживает GET, а клиент отправил POST.

## Как воспроизвести в тестах
1. Найти endpoint с описанным методом.
2. Отправить запрос другим методом.
3. Проверить, что API возвращает 405.

## Как проверить в Postman
Выбрать неправильный метод, например POST вместо GET, отправить запрос и проверить статус 405.

## Как проверить через curl
```bash
curl -X POST https://example.com/api/users/1
```

## На что обратить внимание QA
Проверь, что тело ошибки понятное и не раскрывает внутренние детали сервера.
