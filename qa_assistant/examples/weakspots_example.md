# /weakspots example

## Вход

`/weakspots Пользователь может загрузить файл. Файл должен быть небольшим. После загрузки система показывает сообщение.`

## Идеальный ответ

| ID | Тип проблемы | Фрагмент требования | Почему это проблема | Вопрос разработчику/аналитику |
|---|---|---|---|---|
| WS-001 | Неизмеримый критерий | Файл должен быть небольшим | Не указано максимальное значение размера файла | Какой максимальный размер файла в МБ? |
| WS-002 | Неописанный edge case | Пользователь может загрузить файл | Не указаны допустимые форматы | Какие расширения файлов разрешены? |
| WS-003 | Неясное поведение ошибки | После загрузки система показывает сообщение | Не описано сообщение при ошибке загрузки | Какой текст должен быть при неуспешной загрузке? |
