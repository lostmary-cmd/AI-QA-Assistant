# /checklist example

## Вход

`/checklist Форма регистрации: имя, email, пароль, подтверждение пароля, чекбокс согласия.`

## Идеальный ответ

## UI
- [ ] Поля имя, email, пароль и подтверждение пароля отображаются
- [ ] Чекбокс согласия отображается
- [ ] Кнопка регистрации отображается

## Функционал
- [ ] Регистрация проходит с валидными данными
- [ ] Пароль и подтверждение пароля должны совпадать
- [ ] Без согласия с правилами регистрация недоступна

## Граничные случаи
- [ ] Минимальная допустимая длина пароля принимается
- [ ] Максимальная допустимая длина имени принимается

## Негативные проверки
- [ ] Невалидный email не принимается
- [ ] Пустые обязательные поля показывают ошибки

## Smoke
- [ ] Форма открывается
- [ ] Пользователь может зарегистрироваться с валидными данными
