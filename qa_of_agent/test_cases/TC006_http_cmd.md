# Тест-кейсы на команду /http

| ID | Входные данные | Ожидаемый ответ | Критерии качества |
|---|---|---|---|
| /HTTP-001 | `/http 405 Method Not Allowed` | Объяснение кода, причины, воспроизведение, Postman и curl | Ответ соответствует формату команды; есть минимум 5 релевантных пунктов; язык русский |
| /HTTP-002 | `/http` | Агент сообщает, что данных недостаточно | Не придумывает функциональность; просит добавить описание |
| /HTTP-003 | `/http asdf qwer 123 !!!` | Агент просит уточнить задачу | Не генерирует бессмысленный ответ; объясняет, каких данных не хватает |
| /HTTP-004 | `/http Очень длинное описание с большим количеством условий, спецсимволами !@#$%^&*() и несколькими ограничениями` | Агент обрабатывает ввод без ошибки | Не ломает формат; сохраняет структуру; не обрезает критичные данные |
| /HTTP-005 | `/http Smoke: базовая проверка формы логина` | Агент выдаёт минимально полезный ответ | Есть базовые проверки; ответ можно использовать QA-инженеру |
