# Тест-кейсы на команду /bugreport

| ID | Входные данные | Ожидаемый ответ | Критерии качества |
|---|---|---|---|
| /BUGREPORT-001 | `/bugreport При входе с валидными данными появляется 500 ошибка` | Структурированный баг-репорт | Ответ соответствует формату команды; есть минимум 5 релевантных пунктов; язык русский |
| /BUGREPORT-002 | `/bugreport` | Агент сообщает, что данных недостаточно | Не придумывает функциональность; просит добавить описание |
| /BUGREPORT-003 | `/bugreport asdf qwer 123 !!!` | Агент просит уточнить задачу | Не генерирует бессмысленный ответ; объясняет, каких данных не хватает |
| /BUGREPORT-004 | `/bugreport Очень длинное описание с большим количеством условий, спецсимволами !@#$%^&*() и несколькими ограничениями` | Агент обрабатывает ввод без ошибки | Не ломает формат; сохраняет структуру; не обрезает критичные данные |
| /BUGREPORT-005 | `/bugreport Smoke: базовая проверка формы логина` | Агент выдаёт минимально полезный ответ | Есть базовые проверки; ответ можно использовать QA-инженеру |
