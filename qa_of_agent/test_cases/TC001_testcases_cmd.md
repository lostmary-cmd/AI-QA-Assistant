# Тест-кейсы на команду /testcases

| ID | Входные данные | Ожидаемый ответ | Критерии качества |
|---|---|---|---|
| /TESTCASES-001 | `/testcases Форма логина: email обязателен, пароль 8-32 символа` | Таблица тест-кейсов с позитивными, негативными, граничными и smoke сценариями | Ответ соответствует формату команды; есть минимум 5 релевантных пунктов; язык русский |
| /TESTCASES-002 | `/testcases` | Агент сообщает, что данных недостаточно | Не придумывает функциональность; просит добавить описание |
| /TESTCASES-003 | `/testcases asdf qwer 123 !!!` | Агент просит уточнить задачу | Не генерирует бессмысленный ответ; объясняет, каких данных не хватает |
| /TESTCASES-004 | `/testcases Очень длинное описание с большим количеством условий, спецсимволами !@#$%^&*() и несколькими ограничениями` | Агент обрабатывает ввод без ошибки | Не ломает формат; сохраняет структуру; не обрезает критичные данные |
| /TESTCASES-005 | `/testcases Smoke: базовая проверка формы логина` | Агент выдаёт минимально полезный ответ | Есть базовые проверки; ответ можно использовать QA-инженеру |
