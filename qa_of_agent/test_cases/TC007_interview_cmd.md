# Тест-кейсы на команду /interview

| ID | Входные данные | Ожидаемый ответ | Критерии качества |
|---|---|---|---|
| /INTERVIEW-001 | `/interview junior` | 10 вопросов с ответами, ошибками и подсказками интервьюеру | Ответ соответствует формату команды; есть минимум 5 релевантных пунктов; язык русский |
| /INTERVIEW-002 | `/interview` | Агент сообщает, что данных недостаточно | Не придумывает функциональность; просит добавить описание |
| /INTERVIEW-003 | `/interview asdf qwer 123 !!!` | Агент просит уточнить задачу | Не генерирует бессмысленный ответ; объясняет, каких данных не хватает |
| /INTERVIEW-004 | `/interview Очень длинное описание с большим количеством условий, спецсимволами !@#$%^&*() и несколькими ограничениями` | Агент обрабатывает ввод без ошибки | Не ломает формат; сохраняет структуру; не обрезает критичные данные |
| /INTERVIEW-005 | `/interview Smoke: базовая проверка формы логина` | Агент выдаёт минимально полезный ответ | Есть базовые проверки; ответ можно использовать QA-инженеру |
