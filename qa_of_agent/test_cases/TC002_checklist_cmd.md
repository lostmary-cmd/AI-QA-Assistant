# Тест-кейсы на команду /checklist

| ID | Входные данные | Ожидаемый ответ | Критерии качества |
|---|---|---|---|
| /CHECKLIST-001 | `/checklist Форма регистрации: имя, email, пароль` | Чек-лист по блокам UI, функционал, граничные случаи, негативные проверки, smoke | Ответ соответствует формату команды; есть минимум 5 релевантных пунктов; язык русский |
| /CHECKLIST-002 | `/checklist` | Агент сообщает, что данных недостаточно | Не придумывает функциональность; просит добавить описание |
| /CHECKLIST-003 | `/checklist asdf qwer 123 !!!` | Агент просит уточнить задачу | Не генерирует бессмысленный ответ; объясняет, каких данных не хватает |
| /CHECKLIST-004 | `/checklist Очень длинное описание с большим количеством условий, спецсимволами !@#$%^&*() и несколькими ограничениями` | Агент обрабатывает ввод без ошибки | Не ломает формат; сохраняет структуру; не обрезает критичные данные |
| /CHECKLIST-005 | `/checklist Smoke: базовая проверка формы логина` | Агент выдаёт минимально полезный ответ | Есть базовые проверки; ответ можно использовать QA-инженеру |
