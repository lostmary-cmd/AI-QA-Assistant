# Метрики качества ответов агента

Каждый ответ оценивается по шкалам:

## Полнота, 0-10
Проверяем, все ли обязательные пункты присутствуют.

## Точность форматирования, 0-10
Проверяем, соответствует ли ответ нужному шаблону.

## Релевантность, 0-10
Проверяем, отвечает ли агент именно на запрос.

## Отсутствие галлюцинаций, 0/1
1 — агент не выдумал факты.
0 — есть выдуманные детали.

## Язык ответа совпадает с входом, 0/1
1 — язык совпадает.
0 — язык не совпадает.

## Итоговая оценка
Можно считать так:

`score = completeness + formatting + relevance + no_hallucinations*10 + language_match*10`

Максимум: 50.
