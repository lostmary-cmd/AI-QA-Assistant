# Обзор AI QA Assistant

AI QA Assistant — это агент для помощи QA-инженеру.

## Основная идея

Обычно QA-инженер тратит много времени на:
- тест-кейсы;
- чек-листы;
- анализ требований;
- баг-репорты;
- подготовку негативных проверок;
- объяснение HTTP ошибок;
- подготовку к собеседованиям.

Агент автоматизирует черновую работу. QA всё равно должен проверять ответ, потому что ИИ может ошибаться.

## Архитектура

```text
Пользователь → cli.py → agent.py → prompts/*.md → LLM API → ответ
```

## Почему промпты лежат отдельно

Так их проще тестировать и улучшать. Если команда `/negative` отвечает плохо, мы правим только `negative_prompt.md`, а не весь код.

## Главный риск

Агент может:
- придумать лишние требования;
- нарушить формат;
- дать слишком общий ответ;
- пропустить edge cases.

Поэтому для агента создана отдельная QA-система в папке `qa_of_agent`.
